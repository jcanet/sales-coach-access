# Sales Coach · enlace de acceso

Página pública que abre Sales Coach en su dirección actual. No contiene código del backend, datos, contraseñas ni conversaciones.

La página se publica desde `main`. La rama `live` contiene únicamente `target.json`, actualizado por el servidor cuando cambia el túnel y el destino está sano. El navegador consulta ese JSON al abrir la página; no necesita esperar una nueva publicación de GitHub Pages.

El código fuente y la operación se mantienen en el repositorio privado de la app, en `deploy/public-link/` y `deploy/remote/public-link.sh`. No editar esta copia a mano.
